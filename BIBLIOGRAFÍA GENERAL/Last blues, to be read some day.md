# Last Blues, to Be Read Some Day

'T was only a flirt  
you sure did know –  
some one was hurt  
long time ago.

All is the same  
time has gone by –  
some day you came  
some day you'll die.

Some one has died  
long time ago –  
some one who tried  
but didn't know.
